Comment ça marche

Écouter pour profiter, Sculpter pour régler le son, Composer pour écrire accords, mélodies et morceau. Ambient joue tout seul : cinq couches (Drone, Pad, Mélodie, Grains, Texture) improvisent dans la gamme choisie, et la Dérive fait bouger lentement les réglages autour des tiens.

Démarrer

  • ✦ Paysage : génère un paysage cohérent selon une humeur
  • Presets : points de départ soignés
  • Scènes A/B : mémorise deux états et glisse de l'un à l'autre (Auto = morph lent)

Jouer

  • Glisser sur l'écran : pad XY (gauche/droite = ombre/lumière, bas/haut = densité)
  • A…L notes · Q…P octave au-dessus · Z…M accords
  • MIDI : notes graves = accords, CC1 densité, CC74 brillance

Sculpter

  • Entrée / ❄ Figer : capture 4 s du son → nuage de grains
  • Mouvements lents : 2 réglages qui bougent tout seuls, très lentement
  • Knobs : glisser, molette, Maj = fin, double-clic = défaut

Composer

  • Progression : choisis tes accords I–VII case par case
  • Mélodie écrite : piano roll (clic, glisser, molette = vélocité, clic droit = probabilité, Alt+glisser = sélection), motifs A–D + chaîne, arpège, ● Rec live
  • Basse et Pulsations : grilles 16/32 pas qui suivent l'accord ; ⚄ Euclidien
  • Automation : dessine la courbe d'un réglage ; Morceau : enchaîne des sections
  • ⬇/⬆ MIDI pour passer dans ton logiciel de musique

Garder

  • Rec WAV ou compressé, durée fixe avec fondu
  • Partager : lien qui contient tout le patch
  • ☾ minuteur de sommeil · ⤢ Écoute plein écran
